# 天気・地震 自動配信/自動更新 修正版

- `/weather-setup`: 全国47都道府県/地方、投稿先、JST時刻、自動配信ON/OFFを一括設定。設定は再起動不要で反映。
- `/earthquake-setup`: 全国/地方、投稿先、最低震度、自動配信ON/OFFを一括設定。
- 全国天気は6地域ずつ並列取得。各APIは既存のタイムアウト/3回再試行を使用。
- 天気/地震監視は自己復帰型ループ。1回の例外後も次回監視を予約。
- 地震は新着イベントIDで重複配信を防止。
- 九州・沖縄地方を一括選択可能。

導入後: `npm install` → `npm run deploy-commands` → `npm start`
